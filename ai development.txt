## 4. What works and what does not yet

*Works:* The prototype runs in a browser. It shows tickets sorted by priority, live SLA countdowns with breach warnings, valid status changes only, a comment thread, and different permissions for requesters, agents and admins.

*Limitations (stated honestly):*
- The prototype stores data in the browser only, so tickets are not shared between users.
- The backend code was checked for syntax errors but has not yet been run against a real PostgreSQL database.
- Not done yet: WebSocket live alerts, a React frontend, cloud deployment of the backend, and the final testing results.
